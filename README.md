# RAG Service — Продакшен-система вопросно-ответного поиска по договорам и банковским документам

Сервис вопросно-ответного поиска (Retrieval-Augmented Generation) на русском языке, построенный на базе **FastAPI**, **Nginx API Gateway**, векторной базы данных **Qdrant** и модели эмбеддингов **`ai-forever/ru-en-RoSBERTa`**.

Проект включает в себя как воспроизводимый пайплайн подготовки данных, чанкинга и экспериментов (`RAG_expierements.ipynb`), так и готовую микросервисную обвязку в Docker Compose для продакшен-инференса.

## Архитектура системы

Все компоненты изолированы внутри внутренней мостовой сети Docker (`internal_net`). Наружу смотрит только порт `8000` API-шлюза Nginx, а ML-сервис и векторная база закрыты от прямого внешнего доступа.

```text
                       ┌─────────────────────────────────────────────────────────────┐
                       │                     Docker Network (internal_net)           │
                       │                                                             │
[Клиент / Frontend] ───┼──► [Nginx Gateway :8000] ──► [FastAPI RAG :8001] ──► [Qdrant :6333]
                       │           │                         │                       │
                       │  • Rate Limit (10r/m)      • ru-en-RoSBERTa (1024d)   • HNSW Cosine │
                       │  • X-Admin-Key Auth        • Prompt Assembly          • Payload Meta│
                       │  • SSE Streaming (no buf)  • LLM Generation                         │
                       └─────────────────────────────────────────────────────────────┘
```

### Настройка ключа Nginx

Для `/api/v1/ingest` задайте ключ через переменную окружения `RAG_ADMIN_KEY` в окружении развёртывания. Используйте случайный ключ из 64 строчных шестнадцатеричных символов. Сформируйте файл секретов и смонтируйте его в контейнер Nginx по пути `/run/secrets/rag_admin_keys.conf` в режиме только для чтения.

```sh
test "${#RAG_ADMIN_KEY}" -eq 64 || exit 1
case "$RAG_ADMIN_KEY" in
  *[!0-9a-f]*) exit 1 ;;
  *) (umask 077 && printf '~^%s$ 1;\n' "$RAG_ADMIN_KEY" > /path/outside/repo/rag_admin_keys.conf) ;;
esac
```

После монтирования проверьте конфигурацию в контейнере командой `nginx -t`.
